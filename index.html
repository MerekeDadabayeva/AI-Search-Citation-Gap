Product Requirements Document (PRD)

Autonomous AI Search Citation Gap & Remediation Engine

V1 MVP Spec

1. Executive Summary & Problem Framing

AI search monitors show when a brand loses visibility in ChatGPT or Perplexity, identifying which competitor pages were cited instead. However, marketing and growth teams face an actionability gap: they spend 45+ minutes manually reading competitor websites to guess what text, statistics, or schema tags to add.

The Autonomous AI Search Citation Gap & Remediation Engine provides deterministic side-by-side parsing and generates an immediate 1-page Markdown Content Brief and a developer Jira story.

2. Data Provenance & Verification Architecture

  • Deterministic Primary Ingestion: Scrapes raw HTML and JSON-LD schemas directly from target URLs.
  • Zero-Extrapolation Constraint: Diffing models return factual claims only if they exist verbatim in the scraped text.
  • Inspectable Raw Payload Drawer: UI provides timestamps, HTTP 200 status, and raw text chunk inspection.
  • Direct Primary Links: Every finding includes an outbound link to the competitor live page.

PEEC-102: Diagnostic Side-by-Side Citation Gap Engine

Component: Analytics-Engine / AI-Gateway | Estimate: 5 Story Points

Sprint Ready

AS A Growth Marketing Manager tracking AI search visibility,

I WANT TO inspect the semantic and entity gap between my domain and winning competitor URLs,

SO THAT I can update my pages with the exact missing data required for LLM citations.

GIVEN a tracked prompt where brand visibility rank is > 2 or unmentioned,
WHEN the user clicks "Inspect Citation Gap" for a target competitor source,
THEN render a side-by-side comparison modal displaying:
  1. Missing JSON-LD schema tags and technical attributes,
  2. Numerical benchmarks and claims present on the competitor page,
  3. A 1-click Markdown remediation brief loaded in < 1.5s (cached state).
AND IF the target competitor URL returns a 403 or anti-scraping block,
THEN fallback gracefully to high-level domain authority signals without throwing a 500 error.
